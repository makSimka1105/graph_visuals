## Возможности

- **Пошаговая анимация** — визуализация работы алгоритма с отображением очередей, стека и приоритетной очереди
- **Сравнение алгоритмов** — запуск двух алгоритмов на одном графе с метриками (шаги, посещённые узлы, время)
- **Гибкие графы** — направленные и ненаправленные, взвешенные и невзвешенные
- **Редактор графов** — создание вручную, пресеты, загрузка своих графов
- **A* и Greedy BFS** — эвристики для ускорения поиска
